# Privacy Policy — RateMyProf for PCC

**Last updated: November 4, 2026**

## Overview

RateMyProf for PCC is a Chrome extension that displays RateMyProfessors ratings inline on the Pasadena City College class schedule. This policy explains what data the extension does and does not collect.

## Data Collection

This extension **does not collect, store, transmit, or share any personal data** of any kind.

Specifically:

- No personally identifiable information (PII) is collected
- No browsing history or activity is tracked
- No cookies are created or read
- No analytics or telemetry are used
- No user accounts or authentication are required

## How the Extension Works

When you browse the PCC class schedule, the extension reads professor names visible on the page and sends them as search queries to the [RateMyProfessors](https://www.ratemyprofessors.com) public API to retrieve ratings. These queries contain only professor names — no user information is ever included.

All data retrieved from RateMyProfessors is stored temporarily **in memory only** for the duration of your browser session and is never written to disk or transmitted elsewhere.

## Third-Party Services

This extension communicates with:

- **RateMyProfessors** (`ratemyprofessors.com`) — to fetch professor ratings and reviews via their public GraphQL API

Please refer to [RateMyProfessors' Privacy Policy](https://www.ratemyprofessors.com/privacy-policy) for information on how they handle data.
